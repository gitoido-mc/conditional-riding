## [0.2.0] - 2026-10-26

### <!-- 0 --> Features
- Cobblemon 1.8.3 support
- Added 'negate' requirement, that accepts inner requirement it should negate against
- Added 'game_mode' requirement that will check game mode of current player
- Added 'player_held_item' requirement that will check held item of current player, like 'owner_held_item'
- Player aware requirements
- Cobblemon 1.8.2 support

### <!-- 3 --> Optimizations
- Made 'match_all' and 'match_any' player aware to pass the player down
- Changed 'permission_node' requirement to be aware of current player
